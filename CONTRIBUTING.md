## 📜 Code of Conduct

By contributing to this project, you agree to:

1. ✅ **Respect all users** — regardless of gender, orientation, or background.
2. ✅ **Never promote harassment, manipulation, or coercion** — the Skill is designed for **consensual, respectful communication**.
3. ✅ **Protect privacy** — never share identifiable information of real people without explicit consent.
4. ✅ **Use psychology ethically** — the methods are based on behavioral science, not exploitation.

## 🛠️ Skill Updates & Improvements

The Skill is hosted in two files:

- `namorar.skill` — The main Skill file for Claude
- `namorar.md` — The Markdown version for other platforms

### When Updating the Skill

1. **Make your changes** to the Skill prompt in `namorar.md` first.
2. **Test it** with Claude, Claude Code, or a local model.
3. **Update both files** — ensure `namorar.skill` and `namorar.md` are in sync.
4. **Describe your changes** in the pull request.

### What Can Be Improved

| Area | Examples |
|------|----------|
| **Prompt Optimization** | Better instructions, clearer phases, more examples |
| **Psychology Integration** | Add new behavioral principles or studies |
| **Cultural Adaptation** | Make the Skill work better in different cultures |
| **Tone & Language** | Make the responses more natural and confident |
| **Bug Fixes** | Address any edge cases or failures |

## 📸 Adding Examples (Screenshots)

We welcome **real‑world examples** that demonstrate the Skill working successfully.

### Guidelines for Examples

| Requirement | Description |
|-------------|-------------|
| ✅ **Must censor names** | Blur, pixelate, or remove all names and usernames |
| ✅ **Must censor faces** | Blur, pixelate, or cover faces in all images |
| ✅ **Must show messages** | Display the conversation text clearly |
| ✅ **Must show the prompt used** | Include the exact command and prompt sent to the AI |
| ✅ **Add your watermark** | Optional: Add your username in a corner of the image |
| ✅ **Brief description** | Explain the context: *"I used the Skill to reply to a story"* |

### What to Include in Each Example

| Element | Description | Example |
|---------|-------------|---------|
| **Prompt Used** | The exact command sent to the AI | `/namorar Faça uma resposta para este post do Instagram` |
| **Attached Media** | Whether an image was attached or not | `📎 Imagem anexada (censurada)` |
| **AI Response** | The 3 options generated by the Skill | `--- FASE 1: DOPAMINA --- ...` |
| **Chosen Reply** | Which option was selected and sent | `"Essa sua foto tem uma coisa..."` |
| **Outcome** | The result of sending the message | `Ela respondeu com um coração ❤️` |

### Example Prompt Formats

Here are some examples of prompts you can use with the Skill:

| Scenario | Example Prompt |
|----------|----------------|
| **Starting a conversation** | `/namorar Quero começar uma conversa com uma garota que postou uma foto na praia` |
| **Replying to a story** | `/namorar Faça uma resposta para este story do Instagram` |
| **Continuing a conversation** | `/namorar Ela respondeu "hahaha". O que eu falo agora?` |
| **With image attached** | `/namorar [anexa imagem] Faça um comentário para esta foto` |
| **From a dating app** | `/namorar Ela deu like no meu perfil. Como começo a conversa?` |
| **Moving to DMs** | `/namorar A conversa no post está boa. Como peço o Instagram dela?` |
| **Relationship mode** | `/namorar Minha namorada postou isso. Quero responder de forma carinhosa e provocante` |
| **After a date** | `/namorar Saímos ontem. Como continuo a conversa hoje?` |
| **Flirty follow-up** | `/namorar Ela mandou "kkkk". Como continuo?` |
| **Getting her number** | `/namorar A conversa está ótima. Como peço o WhatsApp dela?` |

### How to Censor Examples

| Method | Tool | Instructions |
|--------|------|--------------|
| **Blur / Pixelate** | Photoshop, GIMP, Canva | Select the area → Apply Blur or Pixelate filter |
| **Censor with AI** | FaceBlur, FaceSwap, OpenCV | Use AI tools to automatically detect and blur faces and names |
| **Manual** | Paint, Preview, Snapseed | Draw black boxes over names and faces |
| **Watermark** | Canva, Photoshop | Add your username in a corner of the image |

### How to Submit Examples

1. **Create a folder** in the repository: `/examples/[your-username]/`

2. **Add the images** with descriptive filenames:
   ```
   01-prompt.png          # Screenshot of the prompt used
   02-ai-response.png     # Screenshot of the Skill's response
   03-chosen-reply.png    # Screenshot of the chosen message sent
   04-outcome.png         # Screenshot of her reply (optional)
   ```

3. **Create a `README.md`** in your example folder explaining each image and the prompt used.

4. **Open a Pull Request** with your examples.

### Example Image Structure

```
/examples/
└── johndoe/
    ├── README.md
    ├── 01-prompt.png
    ├── 02-ai-response.png
    ├── 03-chosen-reply.png
    └── 04-outcome.png
```

## ⚖️ Ethical Use & Legal Compliance

### Is the Skill Legal?

**Yes.** The Skill uses **behavioral psychology techniques** — the same principles used in marketing, coaching, and therapy.

| Aspect | Legal Status |
|--------|--------------|
| Behavioral psychology techniques | ✅ Legal |
| Conversation starters | ✅ Legal |
| Flirting and dating advice | ✅ Legal |
| Manipulation or coercion | ❌ Illegal and prohibited |
| Harassment | ❌ Illegal and prohibited |
| Use on minors | ❌ Illegal and prohibited |

### Ethical Principles

The Skill is built on **five ethical pillars**:

1. **Consent** — Always ensure the other person is comfortable and willing.
2. **Respect** — Treat others with dignity and kindness.
3. **Honesty** — Be genuine in your communication.
4. **Safety** — Never use the Skill to cause harm.
5. **Empathy** — Understand the other person's perspective.

### What the Skill Does NOT Do

| ❌ Not Designed For | Why |
|---------------------|-----|
| Manipulation | The Skill creates *attraction*, not *control* |
| Harassment | The Skill encourages *respectful*, not *aggressive*, communication |
| Exploitation | The Skill builds *connections*, not *dependencies* |
| Coercion | The Skill promotes *consent*, not *pressure* |

## 📬 Pull Request Process

### Step 1: Fork the Repository

Click **Fork** on the GitHub repository page.

### Step 2: Create a Branch

```bash
git checkout -b my-contribution
```

### Step 3: Make Your Changes

- Edit `namorar.md` or `namorar.skill`
- Add examples to `/examples/`
- Improve documentation

### Step 4: Test Your Changes

- Test the Skill with Claude, Claude Code, or a local model.
- Ensure it works and doesn't introduce bugs.

### Step 5: Commit and Push

```bash
git add .
git commit -m "Brief description of your changes"
git push origin my-contribution
```

### Step 6: Open a Pull Request

1. Go to the original repository.
2. Click **New Pull Request**.
3. Select your branch.
4. Write a clear description of what you changed.
5. Submit the PR.

### Step 7: Wait for Review

- A maintainer will review your PR.
- You may be asked to make changes.
- Once approved, your PR will be merged.

## 🐛 Reporting Issues

### How to Report a Bug

1. Go to the [Issues page](https://github.com/erikraft/flirting-skill/issues).
2. Click **New Issue**.
3. Select **Bug Report**.
4. Fill in:
   - **Describe the issue** — what happened?
   - **Steps to reproduce** — how can we replicate it?
   - **Expected behavior** — what should have happened?
   - **Screenshots** — if applicable.

### How to Suggest a Feature

1. Go to the [Issues page](https://github.com/erikraft/flirting-skill/issues).
2. Click **New Issue**.
3. Select **Feature Request**.
4. Fill in:
   - **Describe the feature** — what would you like to add?
   - **Why is it useful** — how does it help?
   - **How could it work** — any implementation ideas?
